# 简洁输出 Skill

## 概述
这个 skill 提供了教学内容，帮助用户学会如何输出简洁、高效的文本内容。

## 核心原则

### 1. 直接回答问题
- 把答案放在最前面
- 避免冗长的开场白
- 一句话总结核心要点

### 2. 精简表达
- 删除不必要的词语
- 使用列表和分点
- 避免重复

### 3. 突出重点
- 用加粗标记关键信息
- 按重要性排序
- 必要时才提供详细解释

## 示例对比

### ❌ 冗长版本
"您好，感谢您提出这个问题。根据我的分析和理解，我认为最佳的解决方案是首先需要考虑以下几个方面..."

### ✅ 简洁版本
"最佳方案是：
1. 考虑 A 因素
2. 处理 B 情况
3. 验证 C 结果"

## 实践技巧

| 场景 | 简洁做法 |
|------|---------|
| 列表 | 用数字/符号，不写句子 |
| 代码 | 直接给代码块，最少解释 |
| 错误 | 问题 → 原因 → 解决方案 |
| 步骤 | 1、2、3... 简短说明 |
